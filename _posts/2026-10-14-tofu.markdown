ToFu is a semantics-aware fuzzing framework for LLM agent tools. It derives security checks from tool metadata and a corpus of 74 CWE-guided sanitizers, targeting the trust boundary between an LLM orchestrator and the tools it calls.
Applied to 118 open-source MCP servers, ToFu found 253 manually verified vulnerabilities, including path traversal, SSRF, command injection, log injection, and data exfiltration. Crash-based fuzzers detect none of them.
